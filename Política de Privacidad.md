Política de Privacidad para The Fool de Discord

1. Información que Recopilamos
Para garantizar la correcta ejecución de sus funciones, "The Fool" desde ahora "bot" recopila y procesa un conjunto mínimo de datos. Estos incluyen:

Identificadores de Discord: Identificador único de usuario (User ID), identificador de servidor (Guild ID) e identificador de canal (Channel ID).

Datos de Configuración: Preferencias asignadas por los administradores para personalizar el comportamiento del bot dentro de cada servidor.

Registros de Uso y Comandos: Información técnica sobre la interacción con los comandos para supervisar el rendimiento y detectar errores.

2. Uso de la Información
Los datos recopilados se destinan exclusivamente a los siguientes propósitos:

Proporcionar, mantener y optimizar el funcionamiento continuo de las características del bot.

Guardar la configuración de cada servidor de manera personalizada.

Prevenir abusos, garantizar la seguridad del sistema y resolver fallos técnicos.

3. Almacenamiento y Retención de Datos
La información se almacena en bases de datos seguras empleando medidas de protección técnicas adecuadas. Los datos se conservan únicamente durante el tiempo necesario para prestar el servicio. Si el bot es expulsado de un servidor, la información asociada a esa comunidad se elimina de manera definitiva tras un periodo prudencial.

4. Compartición de Datos
No se venden, alquilan ni comercializan datos personales o de interacción a terceros. La información permanece estrictamente restringida, salvo requerimiento legal por parte de las autoridades competentes.

5. Derechos del Usuario y Eliminación de Datos
Los usuarios conservan el control sobre su información. Cualquier usuario puede solicitar la consulta o la eliminación completa de los datos asociados a su ID de Discord mediante los canales oficiales de soporte o utilizando los comandos de gestión de privacidad disponibles en el bot.
